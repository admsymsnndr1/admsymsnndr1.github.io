BPOM Command Center

A strategic executive dashboard that brings the dashboards of BPOM's applications together in one real-time command center. Dashboard eksekutif strategis yang menyatukan dashboard aplikasi-aplikasi BPOM dalam satu command center real-time.

The problemMasalahnya

Each of BPOM's applications has its own dashboard, its own login and its own way of presenting numbers. For leadership, getting an overall picture meant opening many systems one by one. The goal was one place where executives can see the state of the agency's services at a glance and drill down when something needs attention.

Setiap aplikasi BPOM punya dashboard sendiri, login sendiri, dan cara sendiri dalam menyajikan angka. Bagi pimpinan, melihat gambaran keseluruhan berarti membuka banyak sistem satu per satu. Tujuannya adalah satu tempat di mana pimpinan bisa melihat kondisi layanan secara sekilas dan menelusuri lebih dalam saat ada yang perlu diperhatikan.

My rolePeran saya

  • Led a team of three with a project manager and a junior developer.Memimpin tim tiga orang bersama project manager dan junior developer.
  • Designed and built the REST APIs that collect data from the source systems.Merancang dan membangun REST API yang mengumpulkan data dari sistem-sistem sumber.
  • Integrated the Tableau visualisations into the command center and containerised the services with Docker.Mengintegrasikan visualisasi Tableau ke dalam command center dan menjalankan layanan dalam container Docker.

ChallengesTantangan

  • Many sources, many shapes. Each source system exposes its data differently, so the integration layer normalises it into one consistent format before it reaches the dashboard.Banyak sumber, banyak format. Tiap sistem sumber menyajikan datanya dengan cara berbeda, jadi lapisan integrasi menyeragamkannya ke satu format sebelum sampai ke dashboard.
  • Executive-level clarity. The audience has little time, so every view starts with the headline number and offers detail only on demand.Jelas untuk pimpinan. Penggunanya punya waktu terbatas, jadi setiap tampilan dimulai dari angka utama dan detail baru muncul saat dibutuhkan.

ResultsHasilnya

  • 101 application dashboards available from one real-time command center.101 dashboard aplikasi dapat diakses dari satu command center real-time.
  • 333 users use it to follow the agency's services.333 pengguna memakainya untuk memantau layanan BPOM.
